## Reproduce local candidate

From repository root, with Node 22 or compatible ESM runtime:

```sh
node training/agentdesktop/train-agentdesktop-native-policy.mjs
node --test training/agentdesktop/agentdesktop-native-policy.test.mjs
```

The training command compiles ordered declarative policy rules and checks 14 labeled cases. The test suite checks 28 separately stored, author-defined cases plus authorization, conflict and evidence assertions. It writes the compiled model and a locally generated results report in this directory; no device actuation, model inference, remote writes or Veritas calls occur. The result is a **candidate deterministic-policy compilation**, not a statistically trained general-purpose model. This limited fixture set cannot establish field accuracy.
